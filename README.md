\# Team Notice Board

A React-based Team Notice Board application powered by Contentful CMS.

## Features
- View notices
- Search notices
- Sort by date
- Category statistics
- Notice details page
- Responsive UI

## Tech Stack
- React.js
- React Router
- Contentful CMS
- Vercel
